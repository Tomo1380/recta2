# AIチャット テスト質問集

想定される質問を分類し、期待する回答パターンをまとめたもの。
E2Eテスト・手動QAの両方に使用する。

---

## 分類の考え方

| 分類 | 説明 | AIの回答方針 |
|------|------|-------------|
| A. Rectaにある店舗知識 | DBの店舗データで回答可能 | search_stores / get_store_detail で回答 |
| B. 一般知識 | 業界の常識・慣行で回答可能 | get_industry_knowledge で回答 + LINE誘導 |
| C. Rectaにない店舗知識 | 特定店舗の非公開情報が必要 | 「詳しくはLINEで担当者にご相談ください」に誘導 |
| D. NG / 要注意 | 法的・倫理的に回答不可 | 明確に断る or 安全な回答のみ |

## テスト実行の優先度

### Phase 1: 基本動作（最優先）
- A1の1, 2, 7（エリア検索・タグ検索・雰囲気検索）
- D1の51, 52, 53（NG質問が正しく拒否されるか）
- B1の13, 15（一般知識で正しく回答されるか）

### Phase 2: 精度チェック
- A2の10, 11（給与比較系 — 複雑なクエリ）
- B3の23, 24, 29（不安系 — 共感 + 適切な情報）
- C の38, 40, 42（LINE誘導が確実に出るか）

### Phase 3: エッジケース
- 「歌舞伎町で3時まで働けるお店」（closing_time精度 — 既知のバグ修正済み）
- 複合条件: 「六本木でノルマなしの未経験歓迎のお店」
- 存在しない店名: 「Club Fantasyってどう？」
- 日本語以外: 「English please」
