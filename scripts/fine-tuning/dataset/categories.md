# Recta2 Fine-tuning 質問カテゴリ階層

本ドキュメントは GPT-4.1 Mini ファインチューニング用のデータセット
（合計 1000 件）のカテゴリ設計を記述する。各カテゴリは「タネ質問」（手書き）と
「テンプレート展開質問」（自動生成）の2層構造で構成される。

エントリは `dataset/questions-1000.jsonl` に OpenAI ChatML 形式（system / user /
assistant の3メッセージ構造）で出力される。回答は 150〜300 文字程度で、業界用語
（黒服・ヘルプ・場内指名・本指名・同伴・アフター・売り掛け・水揚げ・バック・
ノルマ・場内・ヘルプ・卓・カラオケ等）を正確に使う。LINE 誘導 CTA は含めない
（推論時にラッパーが付加する）。

## テンプレート展開ロジック概要

1. **タネ質問**（手書き）: 各サブカテゴリにつき 5〜10 件、合計 70〜90 件。回答も
   完全手書きで業界用語を正確に。
2. **テンプレ展開**: 残り 900 件強を以下の方法で生成。
   - 質問テンプレ × スロット値の組み合わせ
   - 語尾バリエーション（「？」「教えて」「ある？」「知りたい」「探してます」）
   - 回答もテンプレ + スロット差し込み + 表現ゆらぎ
3. **重複防止**: 生成後にテキスト完全一致をハッシュで除外。テンプレ単位で
   表現バリエーションを 3 種以上持つ。

詳細な実装は `scripts/fine-tuning/generate.mjs` を参照。
